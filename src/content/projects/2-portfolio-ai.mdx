## Executive Summary

Building and maintaining a professional portfolio is one of the most tedious tasks for developers and designers. Non-designers struggle with layout choices, typography hierarchies, and visual token consistency.

This project conceptualizes an **AI-Native Portfolio Generator** that ingests raw, outdated CVs alongside user-provided mood photos or web links, translating them into fully themed, token-governed web layouts using dynamic `.design.md` specifications.

---

## Product Workflow

1. **User Input**: Outdated CV PDF, Photo/Web Link inspiration, and Conversational Q&A.
2. **AI Engine Processing**: Parses CV, asks clarifying prompts for career gaps, and extracts color palette/style rules.
3. **Dynamic Output**: Refined Copy, Custom `.design.md` Theme, and Published Web Code.

---

## Core AI UX Patterns

* **Conversational Gap Analysis**: Filling career gaps dynamically through targeted, conversational Q&A.
* **Zero-Jargon Visual Theme Extraction**: Extracting palettes and fonts from photos without asking for hex codes.
* **Real-Time Token Governance**: Keeping generated components locked to system tokens while preserving full human control over layout density.
